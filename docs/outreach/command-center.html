05 · Build order

Three steps to switch this on

  1. Connect Unipileyou · ~20 min

    Sign up at unipile.com, link your LinkedIn account there, add their MCP server as a custom connector in claude.ai settings. This is the only new subscription.

  2. Approve the write permissionsyou · 2 min

    In an interactive session, allow Pipedrive and Dex writes so pipeline moves and contact notes stop hitting the approval wall.

  3. Wire the loopclaude

    Build the Pipedrive stages, message templates per segment, Dex logging rules, and the reactive drafting routine. You give the target segments; the machine does the rest.
